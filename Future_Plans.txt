   Contacts: presence rings + photos (app, and the web Contacts page too)
   - Presence ring around the round contact picture, for contacts that are
     another extension on this PBX (same place the PTT badge shows today):
       green  = that extension's phone/app is signed in to the PBX now
       yellow = was signed in within the last 30 minutes
       red    = not signed in (offline longer than 30 minutes)
     No ring for outside numbers. Refresh with the contact list (and on
     the app's existing wait/poll), never a separate fast poll.
   - Privacy: each user decides whether others can see their status
     (Settings -> "Show my online status to other users", default ON).
     When off, others see no ring for them at all (not red: "hidden").
     The PBX enforces it in the API, not just the app.
   - Photos:

       * Each user can set a photo on any of their contacts.
       * Per contact that is an extension, the user picks which to show:
         "Their profile photo" (updates when they change it) or
         "My photo for them" (the one this user uploaded). Default: theirs
         if they have one, else this user's, else initials.
       * Resize/compress on upload (e.g. 256x256 JPEG/WebP), size limit,
         images only; serve through the authenticated API; include photos
         in the privacy data download and delete them with the account.

     (what the dashboard "Signed in now" uses) plus a last-seen time per
     extension; new fields in /api/v1/me/contacts (presence: online |
     recent | offline | hidden, photo URL/etag) and upload/delete
     endpoints; docs (myphone.html, android.html) and README.
